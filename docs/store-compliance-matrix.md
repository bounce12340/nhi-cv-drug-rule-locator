# App Store / Google Play 合規矩陣(§30 #14)

行動上架(Phase 4/6)之商店審查義務盤點。**草稿**——法律定性(是否構成醫療器材軟體等)與各項對外聲明文案,須由法律/RA 於送審前核定【待人工確認】。定位不變:本 App 為醫療專業人員之法規資訊查詢工具,不做診斷、治療建議或病人資格判定(fail-closed;RDL-005 界線不變)。

## 共通(兩店皆適用)

| 義務 | 對應措施 | 狀態 |
| --- | --- | --- |
| 醫療資訊正確性與來源可證明 | 僅顯示 governed 資料集內容+版本與 as-of 日期;非驗證資料一律 fail-closed;出處鏈=來源登錄+雜湊複驗 | 【規劃】 |
| 非診斷/治療用途聲明 | 固定顯示「僅供專業參考,不構成診療建議」+人工覆核旗標 | 文案【待核】 |
| 隱私權政策 URL | Phase 2 隱私告知上線後提供;內容對應 Processor Register/Retention Schedule | 【規劃】 |
| 帳號刪除(app 內可發起) | DSR 流程,優先於排程期限(retention schedule) | 兩店均強制【規劃】 |
| 目標客群為專業人員、非兒童 | 資格驗證(ADR-006)+客群申報 | 【規劃】 |
| 加密出口申報 | 僅標準 TLS(豁免類別)仍須申報 | 【規劃】 |

## 法律定性【待核,P0】

- 是否構成醫療器材軟體(SaMD):本 App 僅檢索既定法規資訊、不解讀病人資料,初步評估非屬;以法律/主管機關認定為準,若屬之則另有上市前義務。
- 條款號碼與政策版本以送審時點官方文本為準;本表僅為規劃基準,送審前逐條重查。
