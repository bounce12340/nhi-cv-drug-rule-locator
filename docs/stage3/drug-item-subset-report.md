## 精確 token 法與子字串法差異

精確法把「給付規定章節」以逗號切分，逐 token 去除前後空白，再與三個目標 token 做完整字串相等比較。對照用子字串法則直接在整欄上，以三個完整目標字串逐一執行 `includes`，不建立 token 邊界。

| 方法 | 納入列數 |
| --- | ---: |
| 逐 token 精確相等 | 4,047 |
| 整欄子字串 `includes` | 4,278 |
| 子字串法多納入 | **231** |

被子字串法誤納的章節 token 樣態：

| 章節 token 樣態 | 誤納列數 |
| --- | ---: |
| `8.2.6.1.` | 180 |
| `8.2.6.2.` | 51 |
| 合計 | 231 |

其餘相同數字序列或相鄰章節樣態亦由合成負向測試鎖定為排除，不以近似字串自動納入。
