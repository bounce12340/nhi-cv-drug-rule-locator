# INTERPRET-003:新版表二內容之載體形式認定

- 裁決日:2026-08-05
- 裁決者:RA(專案負責人,RDL-009);會期中結構化答覆「A 全部照案」之 A8
- 程序依據:docs/phase1-intake-runbook.md §9(解釋程序)
- 證據來源:docs/stage3/rules-transcription-t2-report.md(T2)、docs/stage3/table2-new261-derivation-report.md(TC-08)、governed 資料集 statin_table2_only_list(RDL-012,116 資料列)

## 待決問題

新版 2.6.1 中「表二」表題存在但機械切分之內嵌資料列為 0(T2:表一 6 列/表二 0 列;TC-08 候選同訊號 B 系 3→0);而第一資料集之 statin 表二專用清單為 116 筆獨立結構化檔。表二實質內容之載體形式為何,轉錄與統計層均不作認定,留 RA。

## 裁決

**新版表二之品項內容以獨立清單形式存在,不內嵌於 2.6.1 條文本文。** 2.6.1 內之「表二」表題與相關條文為其規範框架;品項清單(116 筆)為獨立載體,已依 RDL-012 入庫。

## 效力與限制

- 解釋層決定:不改變逐字轉錄任何位元組(轉錄如實反映內嵌 0 列);規則引擎 display-only 呈現不受影響。
- 未來品項清單與 2.6.1 條文之「對映式消費」(依代碼連結)屬另一次引擎裁決(RDL-016 未授予)。
- 官方生效版確認程序執行時,以官方載體現況複核本認定;不一致依 runbook §9.4 重裁。
