## 待決問題

2026-09-01 修訂引入之「表一」「表二」數字編號,於舊版 2.6.1 全文與公告本文擷取中均不存在(精確字樣各 0 次),僅見於附件2 修訂對照表(表一 3 次:第 1、7 頁;表二 2 次:第 1、11 頁)。舊版 2.6.1 全文含兩張無數字編號之規定表(表題關鍵標籤:降膽固醇、降三酸甘油酯)。兩個數字編號各對應何者,Stage 3 報告僅列標籤與位置證據,最終認定保留給 RA。

## 裁決

**「表一」與「表二」皆屬新版降膽固醇規定之分表**(舊版規定表 A〔降膽固醇〕之後繼結構;新版將該範疇劃分為兩張編號分表)。

- 位置證據(統計層):附件2 中「表一」「表二」字樣均出現於鄰近降膽固醇表題語境(第 1、7、11 頁);鄰近降三酸甘油酯表題語境者 0 次。
- 語義相容性:與已入庫之 statin 表二專用清單(116 資料列,`data/governed/nhi-lipid-2026-09-01-r1/statin_table2_only_list.csv`)相容——「表二專用」限定以表二為降膽固醇範疇之分表方能成立。
