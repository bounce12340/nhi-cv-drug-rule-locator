# INTERPRET-001:複方產品分類歸屬

- 裁決日:2026-08-02
- 裁決者:RA(專案負責人,RDL-009);會期中結構化答覆
- 程序依據:docs/phase1-intake-runbook.md §9(解釋程序)

## 待決問題

隨附規格書(PROJECT_AUTHORED,見 docs/source-register/companion-spec-readme.md)曾把某一複方產品標記為「無標準分類規則、需人工複核」的邊界案例;經 RA 確認為權威版本的 Master Project Prompt v3.2 §9.5 則對同一產品明文規定分類歸屬(2.6.1 範疇)、要求保留 RA 核定紀錄,並禁止再標示「成分無法分類」。兩份文件對同一產品的處理方式不一致。

## 裁決

**依 v3.2 §9.5 之明文分類辦理(歸屬 2.6.1 範疇)。** 邊界案例結案;該產品不得再標示為無法分類。

## 效力與限制

- 本裁決為解釋層決定:未來規則引擎編碼該產品分類時,以 v3.2 §9.5 與本紀錄為依據,並保留表一/表二最終映射之 RA 核定紀錄(v3.2 §9.5 要求)。
- 本裁決**不**將任何規則、代碼或條文內容帶入 repo;實際編碼仍受 RDL-005 與 governed intake(Stage 3–5)閘門管制。
- 產品識別以收件檔案與 v3.2 §9.5 原文為準,本紀錄依紅線規範不重述其代碼與名稱。
- 若日後官方公告與 v3.2 §9.5 不一致,依 runbook §9.4 重開待決、以新證據重裁。
