# Web / iOS / Android Wireframes(§30 #25)

低擬真線框(文字版)。視覺樣式與品牌不在本文件範圍;所有對外文案以法律核定版為準【待核】。三端共用同一資訊架構(分級見 docs/feature-parity-matrix.md),平台差異僅以註記表達。示意欄位一律以〈〉表示,**不含任何真實或示範代碼字面**。

## W1 查詢畫面(現況 Phase 0)

```text
┌────────────────────────────────────┐
│ ⚠ 示範資料,非健保署核定資料/不可作為申報依據。 │  ← 固定警語列,置頂不可折疊
├────────────────────────────────────┤
│ NHI 心血管用藥規則查詢(示範)                │
│ ┌────────────────────────────────┐ │
│ │ 🔍 輸入藥品代碼或名稱                  │ │  ← 載入即自動聚焦
│ └────────────────────────────────┘ │
│ 資料版本:〈version〉  適用日期:〈as-of〉      │
│ ⓘ 本工具不處理任何病人資料。                 │
└────────────────────────────────────┘
```

## W2 結果:EXACT_MATCH

```text
│ ✅ 已在驗證資料集中(僅表示紀錄存在,不代表給付或資格) │
│ ┌────────────────────────────────┐ │
│ │ 〈藥品名稱(含強度與劑型)〉              │ │
│ │ 代碼:〈code〉   DEMO_DATA_ONLY      │ │
│ └────────────────────────────────┘ │
│ ⚠ 示範警語(同 W1,結果區重複顯示)            │
```

## W3 結果:MULTIPLE_MATCHES

```text
│ ⚠ 多筆相符——系統不自動選取,請人工覆核           │
│ ・〈候選 1:名稱+強度+劑型〉                  │
│ ・〈候選 2:名稱+強度+劑型〉 …(全數列出)        │
│ manualReviewRequired: true              │
```

## W4 結果:NOT_IN_VALIDATED_DATASET(fail-closed)

```text
│ ⛔ 不在已驗證資料集內                        │
│ 不提供猜測、更正或近似建議;請人工查證。            │
│ (日期視窗外/版本不符/近似代碼皆落入本態)          │
│ manualReviewRequired: true              │
```

## 平台註記

- **Web**:Enter 送出;鍵盤導覽與 focus 樣式依 docs/accessibility-criteria.md。
- **iOS**:警語列置於 safe area 內;VoiceOver 依卡片逐區朗讀;返回手勢不得繞過警語。
- **Android**:TalkBack 對應;實體返回鍵行為與 iOS 手勢一致。
- 警語與三態結果為 I 級(三端不可差異);字級、間距、鍵盤與捲動行為屬 E/D 級可依平台調整。
