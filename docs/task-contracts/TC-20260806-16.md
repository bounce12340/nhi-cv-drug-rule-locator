## 2. 範圍(三項)

### 2.1 推導腳本 `scripts/drug-item-subset-derive.mjs`

- **來源雜湊閘門**:讀取後先驗 SHA-256,不符即 **fail closed 並以非零碼結束**,不得產生任何輸出
- **結構閘門**:欄位名稱與順序、欄數、資料列數不符即 fail closed
- **篩選規則(核心)**:「給付規定章節」欄為**逗號分隔清單**;以逗號切分、去除前後空白後,**任一 token 精確等於** `2.6.1.` / `2.6.2.` / `2.6.3.` 者納入。
  - **嚴禁子字串比對**。`8.2.6.1.`、`8.2.6.2.`、`1.3.2.6.`、`4.2.6.`、`6.2.6.` 等值含相同數字序列但屬完全不同章節,子字串法會**多納入 231 列**。此即 deterministic-lookup 不變量 1(近似即拒)在資料層之對應。
- **輸出**:`scratchpad/intake-23715/subset-lipid.csv`
  - 表頭與來源同欄同序(去 BOM),資料列**逐欄原字串搬運**,LF 行尾
  - 保留來源列序;**不去重、不排序、不正規化、不補值**——歷史版本列(同一代號多筆不同有效期間)一律保留,此為 as-of-date 回溯之依據
- **`--check` 模式**:重新推導並與既有輸出逐位元組比對,不符即非零碼
- **`--force-hash-mismatch` 探針旗標**:刻意破壞來源雜湊比對以驗證 fail-closed 路徑;該模式**不得寫出任何檔案**
