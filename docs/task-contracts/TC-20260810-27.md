## 1. 產出:`docs/b-track/B1-cover-letter.md`

一份 **RA 可直接改用的委任函範本**,須包含:

1. **收件與填空欄位**:事務所/顧問名稱、承辦人、日期等以明顯佔位符標示(如 `【事務所名稱】`),使 RA 一眼看出要填什麼。**不得臆造任何真實機構或人名**
2. **委任事項一句話**:請就本軟體是否構成醫療器材軟體出具書面正式意見
3. **附件清單**:B1 委任摘要本身 + 其 §3 所列六份參考文件 + **產品線上網址**(請律師實際操作)。清單須與 B1 §3 一致,不得增刪
4. **關鍵前提之提醒**:明白告知本軟體**已在營運中**,且 RDL-018 記載本次發布未取得 §32 專業簽核係 RA 明示承擔之偏離登記。此段須醒目,**不得埋在附件裡**——受任者應在報價與時程評估前即知悉
5. **期待之交付物**:書面意見,逐項回答 B1 §2 之五題;若定性為醫療器材,另請提供義務清單與時程
6. **回覆時程與報價**:請對方提供預估時程與費用(不得由本文件擅自設定金額或期限)
7. **保密與資料性質說明**:本專案不含病人資料;所附文件為內部設計與治理文件,以及公開之政府開放資料轉錄;請對方依其一般保密義務處理
