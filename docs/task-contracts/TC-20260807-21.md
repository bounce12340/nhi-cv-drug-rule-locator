## 1. 範圍

### 1.1 整合:移除「藥品品項查詢」分頁,公告資料併入主檔卡片

- UI 僅餘**兩個查詢分頁**:「藥品查詢」(預設)與「規則逐字查詢」
- 主檔卡片內,若代碼存在於 RDL-012 生成模組(items-2026-09-01),顯示**明確標示來源的公告資料分區塊**(標示資料集版本),依成員資格呈現:改價(原支付價→初核價格、生效日)、表二歸屬、三個月試用期註記
- 兩資料集之值**並列不合併、不互相覆寫**;各自警語與版本標示保留
- `POST /v1/items/lookup` 與 `POST /v1/drug-items/lookup` **兩個 API 端點皆不動**(additive 相容)

### 1.2 事實標籤與篩選鈕(原 F1)

- 卡片標籤:`本次公告異動`、`三個月試用清單`、`表二品項`(代碼精確成員資格)
- 結果篩選鈕:`全部`+上述三類
- **字眼紅線**:一律事實陳述;禁止 eligibility 黑名單詞彙與「符合/不符合××規定」句式

### 1.3 章節導覽(原 F4)

- 規則逐字查詢結果(2.6.1/2.6.2/2.6.3)加「查看本章節品項」→ 切至藥品查詢分頁套用章節篩選

### 1.4 頁尾義務(S1+S2,RA 已核)

1. **開放資料顯名標示**:「資料來源:衛生福利部中央健康保險署『健保用藥品項查詢項目檔』(政府資料開放平臺),依政府資料開放授權條款第1版利用」
