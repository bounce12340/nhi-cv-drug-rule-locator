## 1. 目標

讓 governed 第一資料集(`nhi-lipid-2026-09-01-r1`,RDL-012 已入庫、雜湊鎖定)成為可查詢內容:醫師輸入健保代碼或英文品名/成分,得到該品項之公告所載資訊,並可連結至既有逐字條文查詢。

## 2. 範圍(七項,缺一不可)

### 2.1 build-time codegen `scripts/items-codegen.mjs`
- 讀 `data/governed/nhi-lipid-2026-09-01-r1/` 四個 CSV,以 `nhi_code` 為鍵合併
- 輸出 `packages/domain/src/generated/items-2026-09-01.ts`,檔頭含 `GENERATED — DO NOT EDIT`、資料集摘要雜湊、RDL-019 指涉(比照 `rules-2026-09-01.ts` 既有格式)
- 匯出 `ITEM_DATASET_VERSION`、`ITEM_DATASET_EFFECTIVE_FROM = "2026-09-01"`、`ITEM_RECORDS`、型別 `DrugItemRecord`
- 記錄欄位(缺者為 `undefined`,**不得補值**):`nhiCode`、`drugNameEn`、`ingredient`、`manufacturer`、`coverageRule`、`priceBefore`、`priceAfter`、`effectiveDate`、`tableClassification`、`ingredientCategory`、`exceptionNote`(兩個 ezetimibe 例外檔之試用期欄,原字串)
- **零語意判斷**:欄位原樣搬運,不推導、不分類、不補齊

### 2.2 domain `packages/domain/src/item-lookup.ts`
`lookupDrugItem({ query, as_of_date, dataset_version? })`,五項不變量全部適用:
1. **代碼**:NFKC→trim→大寫→去空白與連字號,表面檢查 `^[A-Z0-9]{10}$`,**僅精確比對**;差一字元回 `NOT_IN_VALIDATED_DATASET`,不得自動更正或建議
2. **名稱/成分**:僅正規化字元形式、大小寫、重複空白;**不得剝除劑量或劑型**;多筆命中回 `MULTIPLE_MATCHES` 並列出全部,不得自動選取
3. **fail closed**:`as_of_date` 非法、早於 `ITEM_DATASET_EFFECTIVE_FROM`、或 `dataset_version` 不符 → `NOT_IN_VALIDATED_DATASET`
4. 所有非 `EXACT_MATCH` 結果 `manualReviewRequired: true`;`EXACT_MATCH` 僅代表該品項存在於資料集,**不表示給付或病人資格**
5. `sourceTag: "OFFICIAL_TEXT_TRANSCRIBED"`;警語逐字為:

```
官方公告之逐字轉錄(2026-09-01 生效),經保真驗證;價格欄為該公告「藥品已收載品目異動明細表」所載原支付價與初核價格,僅涵蓋本次異動品項,非完整支付價主檔;本工具非健保署系統,查詢結果不可作為申報依據,實際規定與價格以健保署公告為準。
```

### 2.3 漂移防護測試 `packages/domain/src/generated-items.test.ts`
重跑 codegen 並與已提交檔案逐位元組比對;比照既有 `generated-rules.test.ts`。

### 2.4 contracts
`parseDrugItemLookupRequest`:允許清單**恰為** `query` / `as_of_date` / `dataset_version`;任何未知欄位拒絕(病人資料防火牆)。負向測試須含 `patient_id`、`diagnosis`。

### 2.5 API
`POST /v1/items/lookup`;`GET /v1/meta` 追加 `itemsDataset`(additive,不改既有欄位)。結構化日誌**永不含查詢內容**。

### 2.6 UI(apps/clinician/App.tsx)
第三分頁「藥品品項查詢」。結果卡片顯示:健保代碼、英文品名、成分及含量、藥商、**原支付價 → 初核價格(並列比較)**、生效日期、公告所載給付規定條號、表別分類、例外註記。
- 價格為 `undefined` 時顯示「本次公告未列異動」,**不得顯示 0 或空白猜測**
- 警語逐字由 domain 透傳(`{result.warning}`),UI 不得自行改寫
- 既有兩分頁與強制警語、無病人資料聲明**一字不改**
