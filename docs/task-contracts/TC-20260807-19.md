## 2. 範圍(僅 UI)

**唯一允許修改的產品檔案:`apps/clinician/App.tsx`**(及其直接關聯之 UI 輔助檔,若存在於 apps/clinician/src/)。

1. 自分頁列移除「示範藥品查詢」分頁與其畫面;保留其餘三分頁(中文品名〔維持預設〕、官方逐字條文、公告異動明細)

3. 各分頁既有官方警語一字不改
4. 移除後不得殘留無作用之示範分頁 UI 程式碼(dead code 一併清除),但**僅限 UI 層**

- **既有 257 項測試零修改**;若 App.tsx 之外有直接斷言「示範分頁存在」之 UI 測試(預期無),先回報再議,不得逕改
