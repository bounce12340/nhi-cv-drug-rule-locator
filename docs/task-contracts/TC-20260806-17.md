## 2. 範圍(六項)

### 2.1 codegen `scripts/drug-items-codegen.mjs` → `packages/domain/src/generated/drug-items-2026-08-06.ts`

**閘門(全部 fail closed)**:manifest 讀取、檔案 SHA-256、位元組數、欄名與欄序、資料列數。

**表示法(緊湊化,以控制 bundle 體積)**:
1. **依「藥品代號」分組**。派發方已量測:同一代號之非價格欄位**變異數為 0**,分組無損。**codegen 必須於建置時複驗此前提**——若任一代號之非價格欄位不一致,**fail closed 並具體指出該代號位置(僅列號,不輸出代號值)**,不得任選其一。
2. **字串表**:`成分`、`藥商`、`製造廠名稱`、`劑型`、`藥品分類`、`分類分組名稱`、`ATC代碼`、`給付規定章節`、`規格單位`、`單複方` 以索引引用共用字串表(相異值皆 ≤145)。
3. **捨去兩個 URL 欄**(`藥品代碼超連結`、`給付規定章節連結`,佔全部字元 46%)。捨去理由須寫入生成檔檔頭;governed 原檔保留全欄不受影響。
4. **價格沿革**:每個代號一個陣列,元素為 `{ 支付價原字串, 有效起日原字串, 有效迄日原字串, 起日ISO, 迄日ISO }`,**依有效起日升序**排列;4,047 期別全數保留。
5. **民國日期轉換**:`YYYMMDD`(民國年)→ ISO `YYYY-MM-DD`,規則為西元年 = 民國年 + 1911;`9991231` 為無終止哨兵,轉為 `9999-12-31`。轉換須有專屬測試(含跨世紀、月末、哨兵值)。
6. 檔頭:`GENERATED — DO NOT EDIT`、資料集版本、dataset digest、RDL-021、記錄數與期別數。

**體積預算**:生成模組 ≤ **1,200,000 bytes**;報告須載明 Expo web bundle 之實際增量。

### 2.2 domain `packages/domain/src/drug-item-lookup.ts`

`lookupDrugItemMaster({ query, as_of_date, dataset_version? })`,五項不變量全部適用:

1. **代碼**:NFKC→trim→大寫→去空白與連字號,表面檢查 `^[A-Z0-9]{10}$`,**僅精確比對**;近似即 `NOT_IN_VALIDATED_DATASET`,不得更正或建議
2. **名稱/成分**:中文品名、英文品名、成分三者皆可查;**僅正規化字元形式、大小寫、重複空白**,不得剝除劑量或劑型;命中多筆回 `MULTIPLE_MATCHES` 並列出**全部**,不得自動選取或排序偏好
3. **as-of-date 語意(本資料集首次具備)**:以 `as_of_date` 對該代號之價格沿革做**區間比對**(起日 ≤ as_of ≤ 迄日),命中該期別;**無任何期別涵蓋該日期即 `NOT_IN_VALIDATED_DATASET`**,不得回退至最近期別或現行期別
4. 所有非 `EXACT_MATCH` 結果 `manualReviewRequired: true`;`EXACT_MATCH` 僅表該品項於該日期存在於資料集,**不表示給付或病人資格**
5. `dataset_version` 不符即 fail closed
