## 委任事項與問題

請依附件所載產品事實與功能邊界，並參考產品線上實際操作情形，就下列五題逐項提供書面意見：

1. 依《醫療器材管理法》與 TFDA「醫用軟體分類分級參考指引」，本軟體（如 B1 委任摘要 §1 所述功能邊界）是否構成醫療器材軟體？
2. 若**非屬**：請出具可供商店送審與主管機關詢答引用之意見書，並註明**維持非屬定性所繫之功能邊界**（我方理解：不解讀病人個別資料、不輸出診療／資格建議——請確認或修正）。
3. 若**屬**：分類分級為何？QMS（QMS／GDP）、查驗登記、廣告限制等義務清單與時程？
4. 未來若增加「依病人條件比對給付規則」類功能（目前永久排除），定性是否改變？——供產品邊界決策參考。
5. 若定性為醫療器材軟體，對一個**已在營運中**之系統，其立即義務、風險與建議處置順序為何（含是否須暫停服務、補正時程、主管機關溝通方式）？
